## Getting started in 2 minutes

**1. Get the code (once):**
```bash
git clone https://github.com/DuDiablo/Jelling_Techathon.git
cd Jelling_Techathon
```

**2. Start a new task — always from fresh `main`:**
```bash
git checkout main
git pull
git checkout -b feat/my-task
```

**3. Save your work:**
```bash
git add .
git commit -m "feat: short description of what you did"
```

**4. Upload it:**
```bash
git push -u origin feat/my-task
```

**5. Open a Pull Request:** go to the repo on GitHub, click **"Compare & pull request"**, fill in the template, and merge once it looks good.

Stuck? Read [CONTRIBUTING.md](CONTRIBUTING.md) or ask in the team chat.
